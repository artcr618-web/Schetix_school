## school56/

Исходник, из которого бралась программа школы:

- `OOP_OOO_2025.pdf` — основная образовательная программа основного общего
  образования МБОУ СШ №56 (Иваново), 7,7 МБ. Это официальный документ школы,
  и он единственный источник того, ЧТО именно и в каком объёме проходят.
- `oop.txt` — текст того же PDF, вытащенный через pypdf (2,6 МБ). Гораздо
  удобнее для поиска: программа, поурочное планирование на 5—9 классы,
  перечень учебников.

Именно отсюда взяты: учебник Мединского и Чубарьяна для 5 класса,
68 + 34 часа, поурочный план на все 68 уроков, и тот факт, что английского
учебника в программе не значится (искали трижды, тремя разными запросами).

Отсюда же — география 5 класса: учебник Алексеева, Николиной и Липкиной
«География. 5—6 классы» (12-е издание, переработанное, «Просвещение»,
линия «Полярная звезда»), 34 часа из расчёта 1 час в неделю, 3 контрольные,
5 практических и ВПР на уроках 30—31. Поурочный план на 34 урока лежит
в `oop.txt` со смещения примерно `s[546616:554600]`.

Чтобы посмотреть нужное место:

```bash
pip install pypdf          # в каждой новой сессии ставится заново
grep -n "История Древнего мира" "Временные/school56/oop.txt"
```

## Заметка про /tmp

Черновики в `/tmp` не сохраняются между сообщениями. Всё, что должно
дожить до следующего раза, надо класть сюда, в `Временные/`.
Именно поэтому скрипты из `Инструменты/` пишут данные не в `/tmp`, а сюда.
